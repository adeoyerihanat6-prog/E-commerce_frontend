## 📌 About The Project

**Velora** is a modern and responsive e-commerce web application built to deliver a seamless online shopping experience.

The application provides users with an intuitive interface where they can explore products, view product details, manage their shopping cart, and interact with a clean and modern shopping environment.

This project was created to showcase my frontend development skills, focusing on responsive design, reusable components, user experience, and scalable application structure.

# 🚀 Getting Started

Follow these steps to run the project locally.

## Prerequisites

Make sure you have installed:

- Node.js
- npm

## Installation

Clone the repository:

```bash
git clone https://github.com/adeoyerihanat6-prog/E-commerce_frontend.git

Navigate into the project:

cd E-commerce_frontend

Install dependencies:

npm install

Start the development server:

npm run dev

The application will run locally at:

http://localhost:5173
