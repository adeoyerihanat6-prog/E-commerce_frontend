## 📌 About The Project

**Velora** is a modern and responsive e-commerce web application built to provide users with a seamless online shopping experience.

The platform allows users to explore products, view detailed product information, manage their shopping cart, and interact with a clean and intuitive shopping interface.

This project was built to showcase my frontend development skills, focusing on responsive design, reusable components, user experience, and scalable frontend architecture.

# 🚀 Getting Started

Follow these steps to run Velora locally.

## Prerequisites

Make sure you have:

- Node.js installed
- npm installed

## Installation

Clone the repository:

```bash
git clone https://github.com/adeoyerihanat6-prog/E-commerce_frontend.git
```

Navigate into the project:

```bash
cd E-commerce_frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run locally at:

```bash
http://localhost:5173
```
